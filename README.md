# yipingli.dev

Personal site for Yiping Li — PhD student in EECS at UC Merced.

Single static page. No build step, no dependencies: `index.html` carries its own
CSS and JS inline. Fonts come from Google Fonts; everything else is local.

- `index.html` — the whole site
- `cv.pdf` — linked from the page
- `CNAME` — custom domain for GitHub Pages

To work on it locally, serve the directory and open it:

```
python3 -m http.server 8750
```
